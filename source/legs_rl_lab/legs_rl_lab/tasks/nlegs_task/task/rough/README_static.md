# nlegs_rough_static

在原 rough 地形上训练“有速度命令行走，零命令站稳”，并考虑真实下蹲侧的单端限位。
复用 `FlatStaticEnvCfg` 和 `_apply_rough`，不复制训练框架、不新增启动脚本。

## 使用

激活原来的 `unitree_lab` 环境，在仓库根目录运行：

```bash
./legs_rl_lab.sh -t --task=nlegs_rough_static
./legs_rl_lab.sh -p --task=nlegs_rough_static
```

输出目录为 `logs/rsl_rl/nlegs_rough_static/`。本次没有训练策略，也没有切换实机 `common.yaml` 的模型。

### MuJoCo sim2sim

```bash
python source/legs_rl_lab/legs_rl_lab/tasks/nlegs_task/task/rough/sim2sim_static.py
# 指定其他已导出的 run：--run 目录名或绝对路径
# 无窗口回放：--headless --duration 10
```

默认 run 为 `2026-09-18_18-36-41`，需有 `params/deploy.yaml` 和 `exported/policy.pt`。
启动即执行策略，初始站姿和出生高度读取所选 run，不额外插值或修改策略。
聚焦窗口：主键盘/小键盘 `8/2` 前后、`4/6` 左右、`7/9` 转向、`0` 清零速度进入站稳目标；`0` 不是暂停策略。
地形复用 rough 的上坡—30 cm 平台—下楼梯，默认从路线前的平地开始。
`--save-data` 保存目标角、实际角、力矩及命令到所选 run 的 `sim2sim/`。
执行器使用导出的名义 PD/惯量/摩擦和分组随机延迟；不声称复现全部训练域随机化或两个物理引擎完全相同。

## 行为与限位

- 每次重采样命令，35% 环境选择站立；3–6 秒切换命令，让同一个环境经历停步和起步。
- 零命令时相位观测的 sin/cos **都为 0**；关闭步态、抬脚和高度奖励。
- 零命令增加默认站姿偏差惩罚（−1）、关节速度平方惩罚（−0.02）、双脚接地奖励（+0.5）。
- 保留速度跟踪、平衡、防滑及扰动；站稳是软目标，受扰动仍允许迈步。非零小速度及纯转向仍执行行走逻辑。
- actor 仍是 47×10=470 维盲走观测；critic 包含地形扫描，共 2490 维。
- `static_env_cfg.py` 的 `CROUCH_LIMITS` 取自 2026-09-17 实测标定，约束 L/R 的 1–5 号关节各一端；踝 roll 不新增限制。
- 同一张限位表同时用于**绝对目标角裁剪**和仿真 startup 写入 **PhysX 物理关节边界**，原有软限位奖励也会同步更新。
- 另一端仍沿用 USD 已有值，不扩大、不重新辨识；XML/USD 文件均不修改。物理求解器存在数值容差，这不是实际反馈绝不越界的保证。
- 实测左右限位不完全对称，因此这个任务关闭强制镜像增强/镜像损失。其他任务不变。

导出的 `params/deploy.yaml` 保留动作限位原精度，不再将它们舍入到三位有效数字。
现有行走 sim2sim / 部署解析器会读取这些目标角 clip 和零命令相位门控。
`sim2sim_static.py` 加载 limit 场景，将导出 clip 的有限端按 policy→SDK→关节名映射写入 MuJoCo 的运行时物理限位，另一端保留 XML 原值。
因此目标裁剪与物理止挡都生效，但不写回 XML/USD。限位以所选 run 的导出配置为准，不导入当前训练配置或读取实机 common.yaml。

## 2026-09-18 辨识复核：哪些结论可用

复核数据为 09-16 膝关节和 09-17 踝关节归档（踝 roll 原始采集在 09-16）。
重新读取原始命令/反馈 CSV，并用已保存的 Isaac 回放验证留出条件；没有重新操作实机。
下方“复频响误差”同时衡量幅值和相位，膝统计可靠的 1–12 Hz 点，踝统计 1–8 Hz；不是关节角百分比误差。

### 膝关节：原模型偏慢，但不能照抄整套拟合参数

| 留出数据指标 | L4 原模型 → 冻结候选 | R4 原模型 → 冻结候选 |
|---|---:|---:|
| 复频响误差 | 72.54% → 18.52% | 83.91% → 31.93% |
| 轨迹等权位置 RMSE | 3.296 → 1.339 mrad | 2.907 → 1.016 mrad |
| RMSE ≤2 mrad 的条件 | 4/13 → 12/13 | 6/13 → 13/13 |

这说明辨识确实能改善这些测试条件下的仿真响应，不是没有收益。
但候选依赖惯量、增益、摩擦、延迟一起变化：例如 R4 的 armature/gain≈0.04976，接近当前 armature=0.0509，存在明显补偿关系。
不能把候选的增益 2–2.43 倍直接当作应写入实机或全局资产的真实标定。

原模型延迟 20–30 ms，没有覆盖候选的 5–10 ms 等效目标延迟，因此新任务只把膝延迟范围扩至 **5–30 ms**。
它表示模型内部等效响应不确定性，不是测得 CAN 纯通信延迟。
工作点影响也明显：4 Hz、幅值 0.005 rad 时，将中心从 0.010 改为 0.030 rad，L4/R4 增益从 0.510/0.308 变为 0.692/0.657。
因此仅调一个常数延迟或 Kp 仍不能解释所有状态。

### 踝 pitch：小动作存在显著响应门槛，且较低阻尼未被原 DR 覆盖

2 Hz 扫频中，目标幅值 0.01 rad 时响应基本低于可靠分辨率；0.02 rad 时实际/目标幅值约为 L5 0.48、R5 0.50；0.04 rad 时升到约 0.74、0.79。
同一频率的响应比例会随幅值显著变化，支持静摩擦/滞回/死区类非线性，**并未唯一识别具体机制**。
纯固定延迟不能解释这个幅值现象，也不能由此推导脚底与地面的摩擦系数。

L5 的冻结候选仅将延迟从 6 步改为 1 步，其他参数不变，8 个留出条件的位置 RMSE 从 3.711 降至 2.529 mrad，复频响误差从 51.3% 降至 35.0%。
有降低模型等效延迟的单参数证据，但仍未通过全部验收，因此扩展覆盖而不把 5 ms 固定为唯一真值。

另用训练 r1/r2 拟合“目标位置误差、反馈速度 → 电机上报力矩”的线性 PD 关系，再预测 r3、阶跃和低速第 3 回合。
四个踝关节共 32 组留出条件中，拟合关系均比同延迟下的名义 PD 更准确。
r3 单独诊断的 Kp 比例约 0.95–0.98；pitch Kd 比例约 0.85–0.87；roll 约 0.66–0.68，支持纳入更低的阻尼。拟合还包含常量偏置，误差改善并非全部由 Kd 带来。
上报力矩来自电流换算，这不是外置力矩传感器的独立校准，不能将回归系数直接认定为真实物理 Kp/Kd。

### 踝 roll：不能为追踪效果盲目加大 Kd

已有回放显示高 Kd=1 的结果对物理步长敏感：5 ms 改为 2.5 ms，L6/R6 位置 RMSE 从 17.34/13.47 降到 4.72/7.58 mrad。
这里同时涉及积分和 PD 更新频率，不足以唯一归因，但足以说明高阻尼回放可能混有数值效应。
本次保持名义 Kd=0.5，只随机到更低阻尼，不把高 Kd 候选硬塞进训练。
roll 的 0 ms 位置拟合候选同时改了多项参数，没有“只降延迟到 0”的对照；本次保守覆盖 10–30 ms，而不是宣称零延迟。

## 已落地的新任务参数

物理步长仍为 5 ms，策略步长仍为 20 ms。延迟每回合按执行器组抽样，PD 比例每回合按关节抽样。

| 参数 | 原 rough | rough_static |
|---|---|---|
| 膝目标延迟 | 4–6 步，20–30 ms | **1–6 步，5–30 ms** |
| 踝 pitch 目标延迟 | 4–8 步，20–40 ms | **1–8 步，5–40 ms** |
| 踝 roll 目标延迟 | 4–6 步，20–30 ms | **2–6 步，10–30 ms** |
| 踝 pitch Kp 比例 | 0.7–1.1 | 不变，即 Kp 28–44 |
| 踝 pitch Kd 比例 | 0.9–1.5 | **0.7–1.2**，即 Kd 1.4–2.4 |
| 踝 roll Kp 比例 | 固定 1 | **0.85–1.1**，即 Kp 34–44 |
| 踝 roll Kd 比例 | 固定 1 | **0.5–1.0**，即 Kd 0.25–0.5 |

髋执行器、膝名义 PD、惯量、关节摩擦和力矩/转速能力边界全部保留。
没有新增凭空设定的硬死区或整套高摩擦候选；它们尚未通过跨幅值、跨 PD、跨工作点的完整验证。
原来的接触摩擦、基座附加质量、编码器零偏和速度扰动随机化继续保留。

## 边界与验证

膝辨识主要覆盖 q≤0.055 rad、补充记录峰速约 0.69 rad/s 的悬空小运动；实际 rough 步态可到 q≈1.09 rad、速度≈5.4 rad/s。
所以这些数据支持修正**小信号响应的覆盖范围**，不支持重新标定高负载力矩/转速上限，也不能证明它就是实机零速前移的唯一根因。
本次更改仍需新策略训练、仿真对照和实机验收，不能保证仅靠 DR 就消除前移。
