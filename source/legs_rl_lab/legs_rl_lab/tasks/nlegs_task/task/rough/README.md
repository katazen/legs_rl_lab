## 实测单侧限位

膝限位块已拆除，因此 **L4/R4 不加下蹲限位或目标角裁剪**，保留 USD 原有膝活动范围。`rough_env_cfg.py` 的 `CROUCH_LIMITS` 只列左右 1、2、3、5 号关节共 8 个单侧端点；另一端保留 USD 原值，踝 roll 不新增限制。rough_static 的 10 个端点独立保留在 `static_env_cfg.py`。

| 关节 | 限制方向 | rad |
|---|---|---:|
| L5 左踝 pitch | 下限 | -0.3763256275 |
| R5 右踝 pitch | 下限 | -0.4224841688 |

同一张表作为零偏为 0 时的标称边界，用于编码器目标角 clip 和 startup 写入 PhysX 物理关节边界，软限位奖励随之更新。存在随机零偏时，目标先按编码器坐标 clip，再换算为物理目标；机械边界保持不变。XML/USD 不改写，也不从部署配置动态加载训练参数。左右端点不完全对称，因此关闭 rough 的镜像增强与镜像损失。

统一实机部署的走路分支不再叠加旧下蹲膝上限：L4/R4 上界取走路模型自身训练 clip 与 common 的交集，其他部署边界保留。反馈检查、停步和手动慢回同步使用走路边界；下蹲/起身仍使用原边界。已通过原实机日志离线回放和状态机回归，尚未验证修改后的实机行走效果。

## 辨识设置

| 踝 pitch 参数 | 左 L5 | 右 R5 |
|---|---:|---:|
| Kp / Kd | 40 / 2 | 40 / 2 |
| armature | 0.035 | 0.0509 |
| friction | 0.51 | 0.55 |
| dynamic_friction | 0.26 | 0.385 |
| viscous_friction | 0 | 0 |
| 固定目标延迟（物理步 5 ms）| 3 步 / 15 ms | 2 步 / 10 ms |

这是一组悬空步态目标回放的等效候选，以同目标下 `q_sim - q_real` 最小为选择标准。踝 pitch 暂停增益随机化；7 rad/s、26 N·m 暂用原模型值，未辨识真实上限，落地负载和可靠域随机化范围尚未验证。

髋延迟 4–6 步、膝延迟 1–6 步、踝 roll 延迟 2–6 步，踝 roll Kp/Kd 倍率 0.85–1.1 / 0.5–1.0 沿用既有设置。原接触摩擦、基座质量、编码器零偏和速度扰动随机化保留。

2026-09-21：rough 的编码器零偏改为成对建模。每环境、每关节在 reset 时采样 `b ∈ [−0.05, 0.05] rad`，整幕不变；策略读 `q_phys + b − q_default`，编码器目标经原有 clip 后以 `q_cmd − b` 送入仿真电机。critic、奖励和接触使用物理真值。目标不再额外按物理坐标裁剪，以保留零偏造成顶限位的效应；PhysX 机械边界仍有效，膝关节不新增限位。该范围是工程假设，尚未经实测标定。flat/rough_static 保持原行为，实机部署不添加随机补偿。需重新训练；运行中的训练和旧权重不会自动获得此修正，能否减少漂移仍需实机对比。

机身 `base` 质心在本体局部坐标系随机偏移：x ±3 cm、y ±1 cm、z ±2 cm。各环境初始化时独立均匀采样一次，重置时保持；这是工程初始覆盖范围，尚非实测辨识区间。配置直接写在本文件的 `EventCfg.base_com` 中。
